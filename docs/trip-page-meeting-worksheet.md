# Trip Page Meeting Worksheet

Working session with the copywriter to decide what's actually in scope for the new rockbusters.net trip page, and **in what form** each section should take.

Reference wireframes (in this folder):

- `rockbusters-performance-camp.html` — climbing camp, sport-coaching flavour. The primary "ukázka".
- `salzburg-shred-safari.html` — ski/snowboard safari, multi-resort flavour. Useful as a second data point: where it diverges from the climbing-camp template is flagged below.

This worksheet covers the **Trip page only**. The Destination page gets its own worksheet later, once the copywriter has drafted one.

---

## How to use this worksheet

For each section, make two decisions and capture anything notable in **Notes**:

- **Scope** — is this section in or out of v1?
  - **Keep** — ship it as the wireframe shows.
  - **Trim** — keep the section but cut some sub-elements (note which in **Notes**).
  - **Drop** — remove the section entirely from the page.

- **Form** — how rigid is the content shape on the page?
  - **Structured** — fixed sub-shape the copywriter fills into a template (e.g. "3 highlight cards: icon + title + body"). Easier to lay out consistently, harder for the copywriter to break the mould.
  - **Free-form** — a rich-text block the copywriter writes freely. More flexible, but harder to design a strong consistent layout for.
  - **Mixed** — some sub-elements structured, some free-form.

If a sub-element list is shown for a section, mark the **Form** decision for the section as a whole — unless something specifically diverges, which goes in **Notes**.

## Cross-cutting questions for the meeting

These don't fit inside any one section, but are worth a few minutes at the end of the meeting:

- **Section ordering — is it fixed?** Does every trip page render the kept sections in the same order, or can it vary per trip?
- **Section variants by trip type.** Sections 4, 5, 9, 10, 11 above all have a different shape between the climbing and salzburg wireframes. Do we standardise on one shape, support both, or build per-trip-type templates?
- **Mid-page CTAs.** The Performance Camp wireframe inserts a "BOOK YOUR SPOT" CTA mid-page (between Overview and Who-It's-For). Keep, drop, or place differently?
- **Reusable vs per-trip content.** Best candidates for reuse: Section 13 (How to Book), Section 14 (Why Rockbusters), and the FAQ library. Worth a quick yes/no per item.
- **Booking flow trigger.** Where does the BOOK CTA actually go? Same booking form for every trip, or per-trip? Affects the hero booking-box design too.
